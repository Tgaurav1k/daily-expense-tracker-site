# Daily Expense Tracker — website

Public site for the Android app **Daily Expense Tracker & Budget**
(`in.dailyexpensetracker.app`), served by GitHub Pages.

| Page | Purpose |
|---|---|
| `index.html` | Landing page: features, pricing, FAQ, contact |
| `privacy_policy.html` | Privacy policy |
| `terms_and_conditions.html` | Terms and conditions |
| `refund_policy.html` | Refund and cancellation policy |

Used as the merchant Website URL for Google Play and payment-aggregator
onboarding, so the pricing, refund and contact details here must stay accurate.

Edit the files and push; Pages redeploys on its own.
